# C++ Programming Internship Projects

## Overview

This repository contains the projects developed as part of my **C++
Programming Internship at Thiranex**.

The internship provided hands-on experience in applying C++ programming
concepts to practical applications, with a focus on **Object-Oriented
Programming, file handling, input validation, data management, and
problem-solving**.

## Projects

### 1. Bank Management Application

A console-based banking application developed using C++ and
Object-Oriented Programming.

**Features** - Create and manage bank accounts - Deposit and withdraw
money - Check account balance - Display account details - Persistent
data storage using file handling - Input validation

### 2. Library Management System

A console-based system for managing books, members, and issue/return
records.

**Features** - Add and manage books - Add and manage members - Issue and
return books - Search books by title or author - Display books, members,
and issued books - Persistent data storage

### 3. Tic Tac Toe

A two-player console-based Tic Tac Toe game implemented in C++.

**Features** - Two-player gameplay - 3 × 3 game board - Player X and
Player O turns - Input validation - Win and draw detection - Replay
option

## Technologies Used

-   **Standard:** C++11
-   **IDE:** Visual Studio Code
-   **Version Control:** Git & GitHub

## How to Compile and Run

Make sure MinGW GCC is installed and available in the system PATH.

### Compile

``` bash
g++ -std=c++11 -O2 -Wall -Wextra project.cpp -o project.exe
```

### Run on Windows

``` powershell
.\project.exe
```
